asdf/block.h - Low-level binary block API
=========================================

.. note::

   This is a lower-level API, aimed at advanced use cases, for reading and
   writing ASDF binary blocks directly rather than through the higher-level
   :ref:`core/ndarray <asdf/core/ndarray.h>` interface.  It is provided here for
   reference; it is not part of the main API tour above and its interface may
   still change before the 1.0 release.  Most applications should prefer working
   with ndarrays.
